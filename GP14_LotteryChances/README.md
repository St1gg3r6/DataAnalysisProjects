# Lottery Odds Analysis for Mobile App

## Overview

This project supports the development of a mobile application by a medical institute to help lottery addicts better understand their chances of winning. The analysis focuses on the Canadian 6/49 lottery, using probability theory and historical data to answer common questions about lottery odds.

## Contents

- **Probability Calculations:**  
  Functions to compute factorials, combinations, and probabilities for winning the main prize or smaller prizes.
- **Single Ticket Odds:**  
  Calculate the probability of winning the jackpot with a single ticket.
- **Multi-Ticket Odds:**  
  Estimate the chances of winning when playing multiple tickets.
- **Historical Data Check:**  
  Use historical draw data to check if a set of numbers has ever won.
- **Partial Match Odds:**  
  Compute probabilities for matching 2, 3, 4, or 5 winning numbers.

## Data Source

- [Canada 6/49 Lottery Dataset](https://www.kaggle.com/datasets/datascienceai/lottery-dataset)  
  Contains 3,665 draws from 1982 to 2018.
