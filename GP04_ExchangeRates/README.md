# Storytelling Data Visualization on Exchange Rates

## Overview

This project explores and visualizes historical Euro to US Dollar exchange rates using data from the European Central Bank. The notebook demonstrates how to clean, process, and visualize time series data to highlight key financial events, such as the 2007-2008 financial crisis.

## Contents

- **Data Loading & Cleaning:** Import and preprocess the exchange rate dataset.
- **Feature Engineering:** Calculate rolling averages to smooth the time series.
- **Focused Analysis:** Filter data for specific periods (e.g., 2006-2010, 2007-2009).
- **Visualization:** Create clear, storytelling plots to illustrate trends and significant events.

## Key Insights

- The Euro-USD exchange rate peaked at 1.59 during the 2007-2008 financial crisis.
- Rolling averages and focused time windows help reveal underlying trends and anomalies.
