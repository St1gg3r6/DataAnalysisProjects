# SQL Window Functions for Northwind Traders

## Overview

This project demonstrates advanced SQL analysis using window functions on the Northwind Traders sample database. The notebook explores sales, customers, employees, and products to answer key business questions and visualize trends.

## Key Analyses

- **Employee Sales Ranking:** Identify and rank employees by total sales to recognize top performers and support training decisions.
- **Monthly Sales Trends:** Calculate and visualize monthly sales and cumulative totals to track business growth.
- **Month-over-Month Growth:** Measure percentage changes in sales to spot trends and anomalies.
- **High Value Customers:** Identify customers with above-average order values and analyze their order frequency.
- **Category Sales Share:** Calculate the percentage of total sales for each product category to guide inventory decisions.
- **Top Products per Category:** Find the best-selling products within each category.
